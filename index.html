Nouveau ticket

Aucune photo. Un ticket long peut être photographié en plusieurs fois : toutes les photos ajoutées ici forment un seul ticket.

Les photos partent normalement dans le dépôt dès qu'elles sont prises. Ce bouton n'apparaît que si un envoi a échoué, le temps de retrouver du réseau.

Envoie toutes les photos de ce ticket à Gemini, qui en extrait le magasin, la date et le détail des produits. La fiche obtenue reste modifiable avant enregistrement.

Le ticket en cours est conservé sur cet appareil même si tu fermes l'app. Ce bouton l'efface pour repartir de zéro (les photos déjà envoyées restent dans le dépôt).

Réglages

Dépôt GitHub

Le token reste dans le stockage local de cet appareil. Il n'est jamais écrit dans les fichiers publiés.

Vérifie que le dépôt répond, que le token autorise l'écriture, et indique combien de tickets sont déjà enregistrés.

Gemini

Elle aussi reste sur cet appareil uniquement : à saisir une fois par appareil.

La réponse doit rester au format JSON décrit dans la question : l'application s'appuie dessus pour remplir la fiche.

Données

Fichier de données : prix.json — photos rangées dans photos/.

Recharger : relit prix.json sur GitHub et remplace ce qui est affiché ici (utile après une saisie faite depuis un autre appareil). Exporter : télécharge une copie de sauvegarde du fichier sur cet appareil.

Déplacer les données

Dépôt des données actuel : —. Le token enregistré doit pouvoir écrire dans le dépôt de destination.

Copie prix.json et toutes les photos, puis vérifie que chaque copie est identique à l'original. Ne modifie rien dans le dépôt actuel ; peut être relancé sans risque.

Fait pointer l'application vers le nouveau dépôt, sur cet appareil comme sur les autres : l'ancien prix.json est remplacé par un simple renvoi. Les photos restent pour l'instant dans l'ancien dépôt.
